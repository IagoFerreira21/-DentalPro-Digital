# 🦷 DentalPro Digital

Website institucional para clínica odontológica, desenvolvido em **HTML, CSS e JavaScript**, com design moderno e responsivo.

## 📌 Funcionalidades
- Hero section com chamada principal e botões de ação (Agendar Avaliação / WhatsApp).
- Seções de Sobre, Tratamentos, Equipe e Depoimentos.
- Formulário de contato com campos de Nome, Email e Mensagem.
- Integração com WhatsApp para contato rápido.
- Efeito visual de pontos flutuantes na hero section.
- Footer com direitos autorais.

## 🚀 Tecnologias utilizadas
- HTML5  
- CSS3 (incluindo animações)  
- JavaScript
